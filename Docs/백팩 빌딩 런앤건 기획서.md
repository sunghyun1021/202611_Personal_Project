# 백팩 빌딩 런앤건 기획서

작성일: 2026-11-06 · Unity 개인 프로젝트 (가제)

<br>

## 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 주제 | 총알배달 우주반점 모작. 백팩 히어로식 가방 인벤토리를 붙인 횡스크롤 런앤건 |
| 플랫폼 | PC, 싱글 플레이 |
| 엔진 | Unity3D |
| 규모·기간 | 1인 개발, 2026-11-06 \~ 2026-11-24 (19일) |
| 레퍼런스 | 총알배달 우주반점(런앤건·층 진행), Backpack Hero(가방 인벤토리) |

**한 줄 소개**: 층마다 몰려오는 적을 쏘며 나아가고, 층 사이에 얻은 무기와 아이템을 칸 단위 가방에 테트리스처럼 끼워 넣어 전투력을 만드는 게임.

**개발 목표**: 화려한 연출보다 **가방 칸을 계산하는 알고리즘(회전, 배치 판정, 인접 판정, 확장 후보 찾기)을 직접 설계하고 적용**하는 것. 캐릭터·적·아이템의 외형, 명칭, 세계관은 자유롭게 정한다.

<br>

## 2. 핵심 재미

- 모양이 다른 아이템을 좁은 가방에 맞춰 넣는 공간 퍼즐
- 아이템을 붙여 놓으면 강해지는 조합 발견
- 새 아이템을 넣기 위해 무엇을 버릴지 고민하는 선택
- 가방 정비 결과가 다음 층 전투에서 바로 체감되는 성장
- 몰려오는 적을 피하며 쏘는 런앤건의 손맛

<br>

## 3. 게임 플로우

1. 메인 화면 → 새 게임 시작 (기본 가방 + 기본 무기)
2. 층 진행(런앤건): 이동, 대시, 사격
3. HP 0이면 클리어 실패 → 결과 화면, 층 끝에 도착하면 정비 화면
4. 정비 화면: 보상 아이템 3개 중 고르기 → 가방 정리(배치, 회전, 버리기) → 확장 층이면 확장할 칸 고르기 → 다음 층으로
5. 마지막 층 완료시 클리어 → 결과 화면 → 다시 하기 / 메인으로

## 3-1) 층 구성안

| 층 | 적 구성 | 정비 | 특이사항 |
| --- | --- | --- | --- |
| 1~2 | 돌진형 소수 | 보상 선택 | 기본 무기 1개로 시작. 이동·사격·가방 배치를 익힘 |
| 3~4 | 돌진형 + 원거리형 | 보상 선택, 4층 후 가방 확장 | 인접 효과 아이템이 처음 등장하도록 보상 구성 |
| 5~ | 전 종류, 수량 증가 | 보상 선택 | 마지막 층. 끝까지 가면 배달 완료 |

<br>

## 4. 필수 기능

### 4-1) 카메라 · 플레이어 · 런앤건

- 횡스크롤 시점, 카메라는 플레이어를 따라 좌우 이동하며 층의 시작과 끝 너머는 비추지 않음
- 이동 A/D, 대시 Space(대시 중 무적), 마우스 방향 조준 + 좌클릭 발사
- **실드/HP**: 피해는 실드가 먼저 받고, 0이 되면 HP 감소. 일정 시간 피해가 없으면 실드 재충전. HP 0이면 게임 패배
- **가방이 곧 장비**: 가방 안의 모든 무기가 장착된 것으로 보고, 발사 중 각자의 연사 간격대로 함께 발사

### 4-2) 가방 인벤토리 (핵심)

- 칸으로 나뉜 격자. 일부 칸만 처음부터 사용 가능, 나머지는 확장으로 개방
- 아이템은 여러 칸을 차지하는 모양(1칸, 가로 2칸, 세로 3칸, ㄱ자 등)
- 드래그로 배치, 드래그 중 놓을 수 있는지 색으로 미리 표시
- R키로 90도 회전, 사용 불가 칸이나 다른 아이템과 겹치면 배치 불가 (겹칠 때는 **거부**로 결정)
- 버리기 칸에 끌어다 놓으면 삭제
- 가방이 바뀔 때마다 무기 성능과 플레이어 능력치 재계산

### 4-3) 인접 효과 (효과 아이템 2종 이상)

- 상하좌우로 변이 맞닿은 경우만 인정(대각선 제외), 효과를 받는 아이템은 화면에 표시(예: 데미지 +35%)

| 효과 아이템 | 대상 | 효과 |
| --- | --- | --- |
| 탄띠 | 무기 | 데미지 증가 |
| 냉각기 | 무기 | 연사 간격 감소 |
| 확대경(선택) | 무기 | 탄속 증가 또는 관통 추가 |

### 4-4) 보상과 가방 확장

- 층 클리어 시 보상 후보 3개 중 원하는 만큼 가방에 넣고, 넣지 않은 후보는 사라짐. 건너뛰기 가능
- 일정 층마다 가방 확장. 정해진 칸 수만큼 확장할 칸을 고르며, 후보는 **현재 사용 가능 칸과 변을 맞댄 칸**뿐. 칸을 열 때마다 후보 갱신

### 4-5) 적 (2종 이상)

- 돌진형: 플레이어에게 곧장 다가와 근접 공격
- 원거리형: 일정 거리를 두고 투사체 발사
- 도약형·변이는 선택 기능
- 상태 구조: 대기 → 접근 → 공격 → 사망
- 화면 밖 적 경고: 화면 가장자리에 방향과 거리 표시

### 4-6) HUD · 결과 · 옵션

- HUD: 실드/HP 막대, 층 진행도, 화면 밖 적 경고, 피해 숫자
- 일시정지(ESC): 재개 / 가방 보기 / 메인 화면
- 결과 화면: 게임 클리어, 패배, 도달 층, 처치 수, 마지막 가방 모습, 다시 하기/메인 버튼
- 옵션: BGM/SFX 볼륨

<br>

## 5. 기술 설계

- **ScriptableObject**: 아이템 정의(모양, 종류, 기본 수치, 인접 효과)와 층별 적 구성을 데이터로 분리
- **오브젝트 풀**: 여러 무기가 동시에 쏘는 탄환과 적에 적용
- **이벤트 연결**: 가방 변경·피격 시 UI가 알림을 받아 갱신 (UI가 매 프레임 확인하지 않음)

<br>

## 6. 추가구현

> 필수 기능을 모두 마친 뒤 진행하는 **추가구현**. 필수 기능 일정에는 포함하지 않는다.

<br>

### 6-1) 장비 합성

- 개요
> - 정비 화면에서 **같은 아이템 2개를 합쳐 상위 등급 아이템 1개**로 업그레이드한다. 
> - 가방 공간을 차지하는 아이템을 합쳐 칸을 아끼고 더 강한 장비를 만드는 선택이 생긴다.

<br>

- 초안
> - 합성 조건: 같은 아이템 종류 + 같은 등급 2개
> - 결과: 등급 +1 (예: 1등급 → 2등급, 최대 3등급)
> - 능력치: 등급이 오를수록 기본 수치 상승 (예: 대미지 ×1.5, 효과 아이템은 인접 효과량 상승)
> - 모양: 기본은 원래 모양 유지(공간 압박 유지).
> - 합성 방법: 가방 안에서 한 아이템을 다른 같은 아이템 위에 드롭하면 합성. 합성 결과는 드롭 대상 위치에 생성
> - 보상 후보에서 바로 가방의 같은 아이템 위에 드롭해도 합성 가능하게 할지는 구현 중 판단
> - 등급은 아이템 외형 변경 또는 별 표시로 구분
> - 합성 가능한 아이템 위로 드래그하면 하이라이트와 "합성" 안내 표시

<br>

- 고려사항
> - 합성 가능 판정: 두 아이템의 종류와 등급 비교
> - 합성 후 배치 유효성: 결과 아이템이 드롭 대상 자리에 문제없이 들어가는지, 모양이 같으므로 대상 칸 재사용이 자연스러운지 확인
> - 합성 후 인접 효과와 최종 성능 재계산 (기존 재계산 흐름 재사용)
> - 최대 등급 아이템은 합성 불가로 표시

### 6-2) 보스 몬스터 

- 초안
> - 등장 조건 : 최종 스테이지에서 등장
> - 높은 체력, 다양한 공격 패턴 구사
> - 일반 공격 뿐 아니라 기믹적인 부분의 공격도 존재
> - 보스 스테이지 입장 시 카메라 무브를 통한 효과 구현

<br>

### 6-2) 보스 몬스터 

- 개요
> - (6-1처럼 한두 줄로 직접 작성해 보기: 보스가 게임 흐름에서 어떤 역할을 하는지, 플레이어에게 어떤 경험을 주고 싶은지)

<br>

- 초안
> - 등장 조건 : 최종 스테이지에서 등장
> - 높은 체력, 다양한 공격 패턴 구사
> - 일반 공격 뿐 아니라 기믹적인 부분의 공격도 존재
> - 보스 스테이지 입장 시 카메라 무브를 통한 효과 구현

<br>

- 고려 사항
> - 일반 몬스터와의 구조 관계: 기존 몬스터 클래스/데이터를 확장할지, 보스 전용으로 분리할지
> - 공격 패턴 선택 방식: 순서대로 반복 / 랜덤 / 조건 기반(체력, 거리 등) 중 무엇을 쓸지
> - 페이즈 전환 여부, 체력 구간에 따라 패턴이 바뀌는지, 전환 순간에 연출이나 무적 시간이 필요한지
> - 기믹 공격의 대응 수단: 플레이어가 기믹을 "읽고 피할 수 있는" 방법이 있는지
>
>   → 예고 표시 (범위 표시, 모션, 사운드)를 어떻게 줄지, 대응 수단이 장비/가방 시스템과 연결되는지
> - 카메라 연출 중 처리: 연출이 진행되는 동안 입력, 보스 행동, 타이머를 멈출지 (연출 종료 시점에 이벤트 발생)
> - 보스 체력 UI: 일반 몬스터와 다른 전용 체력바(이름, 페이즈 표시)가 필요한지

## 7. 마일스톤

| 회차 | 목표 |
| --- | --- |
| 1 | 기획서 확정, 프로젝트 세팅, 플레이어 이동·대시, 카메라 |
| 2 | 마우스 조준·발사, 무기 데이터(SO), 오브젝트 풀 |
| 3 | 돌진형·원거리형 적, 상태 구조, 피해·실드·HP |
| 4 | 층 진행도, 층별 적 구성 SO, 화면 밖 경고, 기본 HUD |
| 5 | 가방 데이터 구조, 아이템 모양 회전, 배치 판정 |
| 6 | 드래그 앤 드롭 UI, 놓을 자리 색 미리보기, 버리기 |
| 7 | 가방 ↔ 무기 연동, 다중 무기 개별 연사 |
| 8 | 인접 효과 판정·표시, 효과 아이템 2종 |
| 9 | 보상 선택, 확장 후보 계산, 확장 선택 UI |
| 10 | 런앤건 ↔ 정비 루프 연결, 메인·결과·일시정지·옵션 |
| 11 | 에셋 교체, 이펙트 적용, 피해 숫자, 밸런스 조정 |

> 필수 기능이 밀리면 12회차를 버그 수정과 마감에 사용하고, 합성은 구현 가능한 범위까지만 진행한다.

## 9. 리스크와 대응

| 리스크 | 대응 |
| --- | --- |
| 가방 UI·드래그 구현이 예상보다 오래 걸림 | 5\~6회차를 가장 중요한 구간으로 보고, 모양은 3\~4종으로 먼저 검증 |
| 에셋 아이콘이 칸 모양과 안 맞음 | 아이콘을 칸 모양 기준으로 크기 조정하고, 어색하면 모양을 아이콘에 맞춤 |
| 여러 무기 동시 발사 시 성능 저하 | 오브젝트 풀 적용, 무기 수 상한 설정 |
| 합성까지 일정이 닿지 않음 | 합성은 추가구현으로 분리했으므로 필수 완성도 우선 |
